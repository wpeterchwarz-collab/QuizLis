# QuizLis

Vokabel-Lern-App (PWA) im Stil bekannter Karteikarten-Apps – gebaut für Italienisch, funktioniert für jede Sprache.

**Funktionen:** Karteikarten mit Wischen · Lernen mit Spaced Repetition (Multiple Choice → Schreiben) · Test/Klausurmodus mit Note und Timer · Spiele: Match, Blast und Gravity · Import von Listen (auch aus Quizlet) und per Foto (Texterkennung auf dem Gerät) · Wortschatz-Bibliothek mit Basiswortschatz Italienisch Kl. 13 (Bildungsplan BG BW) · Aussprache · Akzent-Leiste · offline nutzbar · Sicherung exportieren/importieren.

## Auf dem iPhone installieren
1. Link in **Safari** öffnen
2. Unten auf **Teilen** tippen → **„Zum Home-Bildschirm“**
3. QuizLis über das neue App-Symbol starten

Alle Daten bleiben lokal auf dem Gerät. Unter *Einstellungen → Sicherung exportieren* lässt sich ein Backup anlegen.

## Hosting
Statische Dateien, gehostet über GitHub Pages (Branch `main`, Ordner `/`). Bei Updates in `sw.js` die `CACHE`-Version erhöhen.
